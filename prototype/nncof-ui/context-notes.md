# 라이트 테마 구현 컨텍스트 노트

## 결정 사항

- 테마 값은 `light`와 `dark` 두 가지로 제한한다.
- 초기 테마는 저장된 사용자 선택, 운영체제 설정, 기존 기본값인 다크 테마 순서로 결정한다.
- 루트 요소의 `data-theme` 속성과 CSS 변수를 사용해 Vue 컴포넌트와 D3 SVG가 같은 테마 값을 공유하도록 한다.
- 파랑·초록·주황 등 상태와 이벤트를 나타내는 의미 색상은 유지하고, 배경·텍스트·테두리 같은 중립 색상만 테마에 따라 바꾼다.
- 테마 토글은 기존 새로고침 버튼 옆에 배치하고 아이콘, 툴팁, ARIA 상태를 함께 제공한다.
